# Sprint Planner

Инструмент планирования спринтов: оценка задач по критериям, расчёт ёмкости команды по ролям и автоматический отбор задач в спринт. Работает полностью в браузере, данные хранятся локально (localStorage), интернет и backend не требуются.

Полное руководство пользователя — [docs/UserManual.md](docs/UserManual.md), оно же открывается в приложении кнопкой ❓.

## Запуск

Приложению нужен локальный HTTP-сервер (двойной клик по `index.html` не сработает — браузер блокирует ES-модули с `file://`).

**Windows:**

1. Установите [Python 3](https://python.org/downloads) (при установке отметьте «Add to PATH»).
2. Двойной клик по `start-server.bat`.
3. Откроется браузер с приложением (если нет — откройте `http://localhost:8123`).

**Linux / macOS:**

```bash
bash start-server.sh
```

и откройте `http://localhost:8123`.

Вместо Python подойдёт любой HTTP-сервер: `npx http-server -p 8123` (Node.js) или `php -S localhost:8123` (PHP).

## Установка как приложение (PWA)

После первого открытия в Chrome/Edge нажмите иконку установки (⊕) в адресной строке → «Установить». Установленное приложение работает без сервера и без интернета.

## Решение проблем

| Симптом | Решение |
|---------|---------|
| Пустая страница | Открыли через `file://` — запустите через HTTP-сервер (см. «Запуск») |
| Приложение «не обновляется» после обновления файлов | Откройте `http://localhost:8123/dev-tools/_clear-sw.html` и подождите 2 секунды — кэш очистится автоматически. Либо DevTools (F12) → Application → Service Workers → Unregister + Ctrl+Shift+R |
| Порт 8123 занят | Измените порт в `start-server.bat` / `start-server.sh` (например, на 8124) |
| Не открывается справка (❓) | Убедитесь, что папка `docs/` лежит рядом с `index.html` |
| Данные пропали | Проверьте, не включён ли приватный режим браузера — localStorage в нём блокируется. Регулярно делайте резервные копии кнопкой «Сохранить» (JSON-файл) |

## Данные

Все данные хранятся в localStorage вашего браузера и никуда не передаются. Данные привязаны к браузеру: смена браузера или компьютера = потеря данных, поэтому регулярно сохраняйте план кнопкой «Сохранить» (экспорт в JSON) и при необходимости восстанавливайте через «Загрузить».
