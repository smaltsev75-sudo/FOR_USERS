Управление критериями оценки задач

Настройте критерии оценки задач для расчета Priority Score. Вес каждого критерия определяет его влияние на итоговый приоритет задачи. Сумма весов всех критериев должна равняться 100%. Аббревиатура (3-5 символов) используется для компактного отображения в интерфейсе оценки задач.
