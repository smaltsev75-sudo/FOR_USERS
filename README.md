# Sprint Planner

Инструмент для объективного и прозрачного планирования спринтов в продуктовой разработке.

Sprint Planner помогает Product Owner формировать бэклог спринта на основе формализованных критериев ценности, объективных оценок трудозатрат и жёстких ограничений по ресурсам команды. Работает полностью в браузере, не требует сервера, базы данных и интернета. Устанавливается как приложение на компьютер и мобильные устройства (PWA).

## Для кого

| Роль | Что даёт приложение |
|------|---------------------|
| **Product Owner** | Воспроизводимый, аргументированный механизм отбора задач. Прозрачная связь состава спринта с OKR. |
| **Scrum Master** | Диагностика перегрузки и недозагрузки ролей. Понимание логики взаимодействия алгоритмов с ёмкостью команды. |
| **Команда** | Прямая зависимость между оценкой трудозатрат и попаданием задачи в спринт. Прозрачные правила. |
| **Стейкхолдеры** | Обоснование состава спринта на основе формализованных критериев и ограничений. |

## Возможности

- **Оценка по критериям** — каждая задача оценивается по нескольким критериям с настраиваемыми весами (OKR, UX, стратегия, риск) → интегральный Priority Score.
- **Трудозатраты по ролям** — оценка в часах по 5 ролям: UI/UX, CA, FE, BE, QA.
- **Контроль загрузки** — мониторинг загрузки каждой роли с визуальными индикаторами перегрузки.
- **3 алгоритма автоотбора** — Matrix, Value Density, Hybrid (подробнее ниже).
- **Drag & Drop** — ручное переупорядочивание задач.
- **Исключение/включение** — ручное управление составом спринта.
- **Отмена удаления** — при удалении задачи появляется кнопка «Отменить» (5 секунд).
- **Импорт/экспорт** — сохранение и загрузка данных в JSON.
- **Автосохранение** — все изменения сохраняются в localStorage.
- **Горячие клавиши** — Ctrl+Alt+N (новая задача), Ctrl+Alt+S (сохранить), Ctrl+Alt+O (загрузить), Ctrl+Alt+F (поиск), Ctrl+Alt+P (печать), Delete (удалить задачу), Esc (закрыть окно). Полный список с macOS-эквивалентами — в `UserManual.md`.
- **Светлая и тёмная тема**.
- **PWA** — установка на рабочий стол, полная оффлайн-работа.

## Алгоритмы отбора задач

Приложение предлагает три алгоритма автоматического отбора задач в спринт. Все три используют жадный алгоритм (greedy knapsack) с проверкой ёмкости по каждой роли.

### Priority-Effort Matrix

Задачи распределяются по 4 квадрантам относительно медиан приоритета и трудозатрат:

| Квадрант | Описание | Стратегия |
|----------|----------|-----------|
| Q1 | Высокий приоритет, низкие трудозатраты | «Лёгкие победы» — берём первыми |
| Q2 | Высокий приоритет, высокие трудозатраты | Стратегические задачи — берём менее тяжёлые |
| Q3 | Низкий приоритет, низкие трудозатраты | Заполнители — дополняем оставшуюся ёмкость |
| Q4 | Низкий приоритет, высокие трудозатраты | Откладываем |

### Value Density

Максимизирует «отдачу» спринта. Сортирует задачи по плотности ценности (Priority Score / Effort) и отбирает жадно. Предпочитает задачи с наибольшей отдачей на час работы.

### Hybrid

Совмещает подходы: для важных задач (Q1, Q2) оптимизирует эффективность (как Value Density), для менее важных (Q3, Q4) — берёт наиболее приоритетные (как Matrix).

## Требования

Для запуска нужен **один из**:
- Python 3
- Node.js
- PHP

Интернет не требуется.

## Установка и запуск

> ⚠️ **Не открывайте `index.html` двойным кликом.** Приложение использует ES-модули и требует HTTP-сервера.

### Рекомендуемый способ — скрипт из папки проекта

| ОС | Команда |
|----|---------|
| Windows | Запустите `start-server.bat` — откроет браузер автоматически |
| Linux / macOS | `bash start-server.sh` — автоопределяет Python 3 / Node.js / PHP |

### Альтернативные способы

```bash
# Python
python -m http.server 8000        # Windows
python3 -m http.server 8000       # Linux / macOS

# Node.js
npx http-server -p 8000

# PHP (Linux / macOS)
php -S localhost:8000
```

После запуска откройте: **http://localhost:8000**

### Доступ с мобильных устройств

Запустите сервер на компьютере и откройте в браузере телефона/планшета:
`http://<ip-компьютера>:8000` (оба устройства в одной Wi-Fi сети).

### Установка как приложение (PWA)

После первого открытия можно установить на рабочий стол или мобильное устройство:

| Платформа | Как установить |
|-----------|----------------|
| Chrome / Edge | Иконка установки (⊕) в адресной строке → «Установить» |
| iOS (Safari) | «Поделиться» → «На экран "Домой"» |
| Android (Chrome) | Меню (⋮) → «Установить приложение» |

После установки приложение работает без интернета и без запущенного сервера.

## Решение типовых проблем

### Запуск

| Проблема | Решение |
|----------|---------|
| `Failed to load module script` | Файл открыт через `file://` — запустите через HTTP-сервер |
| Порт 8000 занят | Используйте другой порт: `python3 -m http.server 8080` |
| `Permission denied` (Linux) | Используйте `bash start-server.sh` |
| Не найден Python / Node.js / PHP | Установите [Python 3](https://python.org) или [Node.js](https://nodejs.org) |

### Работа в браузере

| Проблема | Решение |
|----------|---------|
| Пустая страница | DevTools (F12) → Console → найдите ошибку; используйте Chrome/Firefox/Safari |
| Данные пропали после перезагрузки | Проверьте, не включён ли приватный режим (localStorage заблокирован) |
| Приложение не обновляется | DevTools → Application → Service Workers → Unregister → обновите страницу |
| Не открывается справка | Проверьте наличие файла `UserManual.md` рядом с `index.html` |
